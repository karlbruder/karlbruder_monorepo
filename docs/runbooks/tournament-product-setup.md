# Configure tournament registration products

**Created**: 2026-11-14
**Last updated**: 2026-11-27

Guild staff configure registration products in the application. Confirm the
name, description, BRL price, and included benefits with the tournament organizer
before opening registration. Event values remain configuration inputs.

1. Sign in as an admin and open **Administração → Torneios**. Create a tournament
   or open an existing one.
2. Under **Produtos de inscrição**, select existing products to reuse or add new
   products with their names, descriptions, and prices. During creation, save the
   tournament to create its new products and associations together. For an existing
   tournament, choose **Adicionar produto** and save the selection.
3. Review each listed offering. Check its description, current price, and active
   status before opening registration. A product without an active price cannot
   be selected for a new registration. Once registration is open, check the
   participant page for the intended options and prices without submitting a registration.
4. To edit details, change a price, or deactivate a product, choose the relevant
   action. Review every linked tournament shown on the confirmation screen.
   Confirm only when the effect on all of them is intended. Deactivation removes
   the option from new registrations in every linked tournament.

A changed amount creates a new price record. Existing registrations retain the
product name, description, and amount captured when they were created. Do not
edit historical price records or order items to change an offering. Reusing a
product links the same product to another tournament, so future changes affect
all linked tournaments. See [catalog rules](../../specs/tournaments/catalog.md#rules)
and [registration rules](../../specs/tournaments/registration.md#rules).
