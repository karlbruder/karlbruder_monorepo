# Frontend

These instructions apply to `frontend/` and everything under it. They add to the repository root [AGENTS.md](../AGENTS.md). Read both.

## Tests

The `it` or `test` title is the description. Write one short sentence that says what the test does and what result it locks in.

When that title already says both, do not add a comment above the test. Add a comment only when the title still hides the point.

## Comments

Do not add a comment that only restates the next line. A module docstring is fine. A section separator is fine. A short class or function docstring is fine when it adds something the name does not already say. When a class or function is hard to follow, the docstring may explain the reason and give an example. Comment on a line when the reason is not visible in the code.
